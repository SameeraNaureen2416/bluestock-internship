# Statistics for Data Analysis – Beginner Notes

## Mean
Average value: sum of observations / number of observations.

## Median
Middle value after sorting. Useful when data contains extreme values.

## Mode
Most frequently occurring value.

## Standard Deviation
Measures how spread out observations are around the mean.

## Correlation
Measures the strength and direction of a linear relationship. Correlation does not prove causation.

## Probability
Probability represents how likely an event is. It ranges from 0 to 1.

## Introductory Regression
Regression estimates a relationship between a dependent variable and one or more explanatory variables. In simple linear regression:

`y = b0 + b1*x + error`

## Example using the sales dataset
Possible questions:
- Does quantity have a linear relationship with sales amount?
- How does monthly sales vary?
- Which states have higher average order value?

Use Python/Pandas to calculate statistics and Matplotlib for visualization.
