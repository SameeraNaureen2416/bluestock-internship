# Software Development Fundamentals

## Frontend vs Backend
The frontend is the user-facing interface. The backend receives requests, validates inputs and performs business logic.

## REST APIs
REST APIs allow software systems to exchange resources over HTTP.

## Authentication
Authentication verifies identity. Authorization determines what an authenticated user is allowed to do.

## Databases
Databases persist structured application data and support querying.

## Data pipelines
A data pipeline moves data through ingestion, validation, transformation and storage so it can be analyzed.

## Logging and error handling
Logging records useful events for troubleshooting. Error handling prevents failures from becoming confusing or silent.

## SDLC
A typical lifecycle is:
Requirements → Design → Development → Testing → Deployment → Monitoring → Maintenance.
