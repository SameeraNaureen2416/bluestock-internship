The sales dataset is **synthetic practice data** created specifically for this prerequisite. It is not company/customer data.

The Power BI folder is Power BI-ready. A native `.pbix` file should be created and saved in Power BI Desktop; no fake `.pbix` is included.

### Python
```bash
cd 03_Week1_Python
python sales_analysis.py
```

### SQL
Open `02_Week1_SQL/sales_analysis.db` with SQLite or run `queries.sql`.
